# Topologi Aljabar — Edisi Bahasa Indonesia, Unit 1–13

Versi: `0.13.0`  
Tanggal: 22 Agustus 2026  
Status: **batas preservasi terpelihara; edisi lengkap masih diproduksi**

Penulis karya sumber: **David Michael Roberts**.  
Editor edisi Bahasa Indonesia: **Floris**.

Rilis ini mencakup Kuliah 1–13 dari *Algebraic Topology* karya David Michael
Roberts, yaitu `Notes.tex` baris 134–3046 pada komit sumber
`b947ad2e9f9e301bfe24590a9db653bc54fa1a53`. Cakupannya berhenti setelah
kompleks presentasi; unit-unit berikutnya tidak diklaim sudah selesai.

## Berkas pembaca

- `00_TOPOLOGI_ALJABAR_ID_UNIT_001_013_READER.pdf`: PDF deterministik untuk
  pembacaan dan pencetakan. PDF ini belum bertag dan merupakan artefak sekunder.
- `TOPOLOGI_ALJABAR_ID_UNIT_001_013_READER.html`: pembaca utama yang mandiri,
  dapat digunakan luring, berbahasa `id-ID`, memakai MathML asli, terpusat dan
  reflow pada layar sempit.

## Sumber, backend, dan bukti

- `TOPOLOGI_ALJABAR_ID_UNIT_001_013_EDITABLE_SOURCE_BACKEND.zip`: sumber
  Markdown Unit 1–13, backend JSONL ber-ID stabil, stylesheet, atribusi,
  pernyataan hak, serta saksi sumber resmi. Arsip ini tidak memuat skrip
  perangkat lunak, program pembangunan, atau berkas dapat-dieksekusi.
- `TOPOLOGI_ALJABAR_ID_UNIT_001_013_QA_PROVENANCE.zip`: hasil QA kumulatif,
  ulasan independen per unit, saksi teks PDF, ledger koreksi, provenance, dan
  kontrol otoritas yang relevan dengan rilis dan telah disanitasi. Arsip ini
  tidak memuat `CURRENT_STATE`, `CURSOR`, `TASK_SCOPE`, catatan tujuan/seleksi,
  kredensial, jalur pengguna absolut, atau skrip perangkat lunak.
- `RELEASE_RIGHTS.md`: cakupan lisensi dan atribusi tepat untuk setiap komponen
  deposit.
- `release-manifest.json` dan `SHA256SUMS`: inventaris byte dan SHA-256 berkas
  rilis.

HTML dan PDF dibangun dua kali dengan hasil byte-identik. QA struktural,
browser desktop/seluler, pemeriksaan rumus dan tautan, pemeriksaan font PDF,
serta inspeksi visual seluruh halaman dicatat dalam paket provenance.
