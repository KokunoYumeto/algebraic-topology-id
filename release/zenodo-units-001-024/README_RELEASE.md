Rilis ini mencakup Kuliah 1–24 dari *Algebraic Topology* karya David Michael
Roberts, tepatnya `Notes.tex` baris 134–5369 pada komit
`b947ad2e9f9e301bfe24590a9db653bc54fa1a53`. Baris 5370 memulai Kuliah 25 dan
ditunda utuh ke unit berikutnya. Kuliah 25–30, jembatan homologi Fomberg, dan
lapisan pembuktian, latihan, laboratorium, serta capstone penutup belum termasuk
dan tidak diklaim selesai.

## Mulai membaca

1. `00_TOPOLOGI_ALJABAR_ID_UNITS_001_024_READER.pdf` adalah berkas pembaca
   pertama dan utama: PDF A4 286 halaman dengan font tersemat dan
   `/Lang=id-ID`. PDF ini belum bertag secara struktural.
2. `TOPOLOGI_ALJABAR_ID_UNITS_001_024_READER.html` adalah pembaca mandiri,
   offline, terpusat, dan reflow pada layar desktop/seluler. Ia memakai MathML
   asli, mempertahankan 1.295 ID DOM unik tanpa duplikasi, dan mempunyai nol
   fallback TeX mentah.

## Sumber yang dapat dilanjutkan dan QA

- `TOPOLOGI_ALJABAR_ID_UNITS_001_024_EDITABLE_SOURCE_BACKEND.zip` memuat sumber
  Markdown Unit 1–24, build script kumulatif, backend JSONL ber-ID stabil,
  stylesheet, atribusi, lisensi, saksi `Notes.tex`, serta kontrol terminologi
  yang diperlukan untuk melanjutkan pekerjaan.
- `TOPOLOGI_ALJABAR_ID_UNITS_001_024_QA_PROVENANCE.zip` memuat QA dan review

Paket sengaja tidak memuat kredensial, cache, render sementara, hasil ekstraksi
teks massal, dump koordinasi, atau salinan ganda berkas pembaca.
