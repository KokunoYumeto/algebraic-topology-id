Status: **korpus Roberts lengkap 30/30; kursus komposit tetap parsial**

Rilis ini mencakup seluruh Kuliah 1–30 dari *Algebraic Topology* karya David
Michael Roberts, tepatnya `Notes.tex` baris 134–6368 pada komit
`b947ad2e9f9e301bfe24590a9db653bc54fa1a53`. Baris 6368 adalah
`\end{document}` dan tidak ada Kuliah 31 dalam sumber beku. Batas Roberts
selesai, tetapi jembatan homologi Fomberg dan penutupan pembuktian,
penguasaan, laboratorium, serta capstone orisinal untuk kursus komposit belum
termasuk dan tidak diklaim selesai.

## Mulai membaca

1. `00_TOPOLOGI_ALJABAR_ID_UNITS_001_030_READER.pdf` adalah berkas pembaca
   pertama dan utama. PDF A4 ini memakai font tersemat dan `/Lang=id-ID`,
   tetapi belum bertag secara struktural.
2. `TOPOLOGI_ALJABAR_ID_UNITS_001_030_READER.html` adalah pembaca mandiri,
   offline, terpusat, reflowable pada layar desktop/seluler, dan memakai
   MathML asli tanpa dependensi runtime eksternal.

Jumlah halaman dan metrik HTML yang tepat tidak ditebak di dalam kontrol ini;
semuanya diambil dari receipt build final yang identitas byte-nya dibekukan
oleh `release-manifest.json`.
